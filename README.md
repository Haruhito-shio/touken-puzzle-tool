# 刀剣乱舞ぱずぎり材料规划工具

**touken-puzzle · Material Planner**

一个给刀消审神者用的**突破材料规划小工具**。选好要练的刀、填上等级，它就帮你算出：一共要哪些材料、背包里还缺多少、缺的材料去哪些关卡刷。

纯网页，打开就能用；不用注册、不用登录，数据只存在你自己的浏览器里。

> 数据来源于多位同事共同维护的《刀剣乱舞ぱずぎり统计》在线表格，感谢每一位整理数据的伙伴。

---

## 它能干什么

| 功能 | 说明 |
| --- | --- |
| 📋 **突破计划** | 添加想练的刀剑，设置「当前 Lv → 目标 Lv」，自动算出这一段需要的全部材料 |
| 🎒 **背包对照** | 录入库存后，自动算出「总需求 / 已有 / 缺口」，并显示整体进度 |
| 🗺 **缺口来源** | 一键把缺口材料带到「来源」页，看哪些关卡能刷到 |
| 🔍 **材料来源查询** | 自选一个或多个原材料，查看哪些关卡掉落，按覆盖数量排序 |
| ⚗️ **合成查询** | 选一个或多个半成品，看它拆成哪些基础材料、各要几个、要花多少小判 |
| 📊 **首页统计** | 汇总所有计划的突破阶段：总数、已完成、待完成 |
| 💾 **备份 / 恢复** | 一键导出、导入你的计划和背包，换设备也不怕丢 |
| 🎲 **本丸今日运势** | 纯娱乐小彩蛋（内容由 AI 生成），不影响任何数据 |

## 快速上手（三分钟）

1. **添加刀剑**：打开「突破」页，点搜索框选一把刀，填好当前等级和目标等级，点「加入计划」。
   - 太郎太刀、三日月宗近、一期一振、歌仙兼定、乱藤四郎有「普 / 彩」两套需求，选到时会让你选稀有度。
2. **录入背包**：点右上角「🎒 背包」，把已有的基础材料数量填进去，改完即存。任意页面都能打开，刷完一关随手改就行。
3. **算缺口**：回到「突破」页，点「全部计划：计算缺口」，或勾选部分刀剑后点「用勾选角色计算缺口」。
4. **看去哪刷**：在「材料需求总览」下方点「查看缺口来源」，自动跳到「来源」页并带上缺口材料。

## 各页面说明

### 首页
- **突破阶段统计**：按所有计划合计。
  - **已完成**：某一段突破的终点 ≤ 这把刀的「当前 Lv」，就算完成。
  - **待完成**：还没练到的段。
  - 想标记完成：到「突破」页，把那把刀的「当前 Lv」改到对应等级即可。
- **数据备份**：导出 / 导入 JSON 文件。
- **本丸今日运势**：点「换一换」换一组，点「查看详情」看今日事件。

### 突破页
- 左侧勾选框只用于**本次临时计算**，不会删除或改动已保存的计划。
- 「材料需求总览」显示总需求、已有、缺口、整体进度，并在进度条下方以小字标出**所需小判总数**。
- 小判是游戏货币：用于合成半成品，**不占背包、不计入缺口**，只作参考。

### 来源页
- 只能选**原材料**（基础材料），合成物请去「合成」页查。
- 支持多选：点一下勾选、再点取消；下拉列表不会自动关闭，点空白处、再点一次输入框或按 `Esc` 关闭。
- 结果里的 `x / n` 表示「这个关卡的掉落清单覆盖了 n 种目标材料中的 x 种」，**不代表掉率**。

### 合成页
- 下拉里只列半成品（能合成的材料），支持多选。
- 每个材料显示完整拆解树、基础材料合计和小判花费（含中间半成品的合成费）；选了多个时还有一份总合计。

### 完整背包
- 一次性批量修改全部基础材料库存，改完即存，所有页面的缺口自动更新。

## 计算规则

- **哪些突破段会被计入**：只算「起点 > 当前等级」且「起点 < 目标等级」的段。
  例：5 → 35，会算 10→20、20→30、30→35 三段。
- **半成品自动拆解**：需求里的半成品会递归拆成基础材料，再与背包对照。
- **背包只记基础材料**：半成品不占库存。
- **材料显示名**：中日文一致只显示一个（如「水」）；不一致则显示「日文｜中文」（如「丸太｜木材」）。

## 数据与隐私

- 你的计划和背包只保存在**本机浏览器**（localStorage），不会上传到任何服务器。
- 清理浏览器数据或换设备会丢失，请定期使用首页「导出备份」。
- 备份只包含**突破计划与背包库存**，不包含游戏公共数据。

## 更新游戏数据

游戏公共数据集中在 `game-data.js` 一个文件里，由转换脚本从《ぱずぎり统计》xlsx 生成。数据有更新时：

1. 重新生成 `game-data.js`。
2. 替换仓库里的旧文件并提交。
3. 页面顶栏的「数据更新日期」会自动读取数据里的生成日期，不用手改 HTML。

用户自己的计划与背包不受影响。

## 常见问题

**Q：缺口算出来是空的 / 提示没有计划？**
先在「突破」页添加至少一把刀，再点计算按钮。

**Q：为什么来源页搜不到某个材料？**
来源页只列基础材料。半成品请到「合成」页查它的拆解。

**Q：关卡上的 `x / n` 是掉率吗？**
不是，只表示这个关卡覆盖了几种目标材料。

**Q：换手机后计划没了？**
数据存在浏览器里。在旧设备「导出备份」，新设备「导入备份」即可。

**Q：小判总数为什么不算进缺口？**
小判是游戏货币，不在背包材料里，仅作合成花费的参考。
